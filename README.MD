\# 🤖 Telegram Bot with Redis Cache



Telegram бот для парсинга сайтов с кэшированием в Redis.



\## 📋 Возможности

\- Парсинг новостных сайтов

\- Кэширование результатов в Redis

\- Команды для управления кэшем



\## 🛠 Технологии

\- Python 3.13

\- PyTelegramBotAPI

\- Redis

\- BeautifulSoup4

\- Requests



\## 🚀 Установка



```bash

\# Клонировать репозиторий

git clone https://github.com/ваш-username/my\_telegram\_bot.git



\# Перейти в папку

cd my\_telegram\_bot



\# Создать виртуальное окружение

python -m venv venv



\# Активировать (Windows)

venv\\Scripts\\activate



\# Установить зависимости

pip install -r requirements.txt



\# Создать .env файл с токеном

echo BOT\_TOKEN=ваш\_токен > .env



\# Запустить

python bot.py
